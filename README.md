# TuristPRO

Веб-приложение для бронирования экскурсий и мастер-классов в туристическом городе (дипломный проект).

## Стек

- Python, Flask
- SQLAlchemy, SQLite
- Flask-Login, Flask-Migrate
- Jinja2, HTML/CSS

## Роли

| Роль | Возможности |
|------|-------------|
| **Турист** | Каталог, мгновенное бронирование, имитация оплаты, личный кабинет |
| **Организатор** | Создание мероприятий, расписание, просмотр бронирований |
| **Администратор** | Пользователи, категории, мероприятия, все бронирования |

## Запуск

```bash
# Активировать виртуальное окружение
.venv\Scripts\activate

# Установить зависимости
pip install -r requirements.txt

# Заполнить демо-данными
python seed.py

# Запустить сервер
python run.py
```

Откройте http://127.0.0.1:5000
